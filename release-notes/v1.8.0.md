Activity months and CSV export.

- Activity shows one budget month at a time, with Older and Newer, as Categories does. To sort and Recently sorted still show everything waiting.
- Export CSV on Activity saves what the tab shows for that month as a CSV file, where you pick. One row per line, with the date, description, amount, envelope, category, account, memo and pending. Nothing goes to the server.
- Fixed: dragging an envelope's handle to set the fill order now carries on past more than one envelope in a single drag.
- The app's screens are now shared with the Windows program, so both show the same fields and wording.
- Requires Android 13 or newer.
