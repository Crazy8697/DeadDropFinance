The first published build of Dead Drop Finance.

It opens, shows its name and version, and checks GitHub for newer versions. That's all it does so far: the
budgeting comes in later versions.

- Update check: a few seconds after startup the app asks GitHub whether a newer version is out, and shows a bar
  with Release notes, Download, Skip this version and Later if one is. You can turn the startup check off, or
  check by hand. Nothing about you is sent.
- Requires Android 13 or newer.
