Restore fix.

- Restoring a backup while logged in to your server no longer fails with "The file couldn't be read." The app reads the file you pick once, right away, and uses that copy for the whole restore.
- If a restore fails, the message now says what went wrong: the file couldn't be opened, it's empty, it isn't a backup, it's damaged, the key is wrong, or the server refused. It also says whether anything on this phone changed.
- Fixed: editing an ATM withdrawal no longer loses the envelope the cash came out of.
- Requires Android 13 or newer.
