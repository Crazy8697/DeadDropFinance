A fix for CSV import.

- Import no longer skips identical rows inside one file. Two real purchases or transfers on the same day can look
  the same, so they are now shown under "Possible duplicates in this file", grouped, and imported unless you
  choose to skip them.
- Rows your budget already holds are matched by count. If the file has three identical rows and one is already in
  the app, two are imported. Importing the same file again still adds nothing new.
- Requires Android 13 or newer.
