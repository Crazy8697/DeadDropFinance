Categories, an Unplanned envelope, and an assigned total on Envelopes.

- Categories: every purchase gets a category (Rent, Groceries, Eating out and more; add, rename or delete your own).
  Envelopes can claim categories, so picking a category sorts the purchase into the right envelope. Anything no
  envelope claims goes to Unplanned, a new built-in envelope that counts toward Safe to Spend.
- Categories tab: spending per category for the budget month, with older months and each category's purchases.
  Purchases from before this version show as Uncategorized until you give them one.
- Rules can set a category, and the JSON setup file accepts categories and the categories an envelope claims.
- Envelopes shows how much of this budget month's income is assigned.
- Help is folded into About. Check for updates stays in More.
- Requires Android 13 or newer.
