Fixes Download and install, which didn't open Android's install screen.

- Updates: Download and install now opens Android's own install confirmation, then installs.
- Earlier versions (0.15.1 and 0.15.2) can't update themselves because of this. Install 0.15.3 by hand from this
  release page once; updates after that work from inside the app.
- Requires Android 13 or newer.
