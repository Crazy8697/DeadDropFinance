Sync with your own Dead Drop server.

- More > Server > Connect to server: type your server's address, check its fingerprint against the one the server shows, then create the account with the server's one-time setup code (the first device), or log in with the username and password (every other device).
- The first device's budget becomes the server's copy. A device that logs in takes the server's budget; if it had one of its own, an encrypted backup of it is saved to Downloads/DeadDropFinance first, opened with the account password.
- Changes go both ways. Made while offline, they wait (even if the app closes) and go once the server can be reached. When two devices change the same thing, the later change wins and the other device gets a note.
- One device edits at a time: the app holds the edit lock while it's on screen and lets go when it goes to the back. While another device holds it, this one is read only, with a banner naming that device.
- The status (Not connected, Syncing, Synced, Offline with what's waiting, or an error) shows on Home and the Server screen, with when it last synced and Sync Now. The Server screen lists your devices, can remove one, and logs out.
- Everything between the app and the server is encrypted (libsodium). The password is never kept on the phone. The server's key is remembered the first time, and a different key later is refused.
- Payday without Fill envelopes now sweeps the month's leftovers into Rollover. Edit transaction on a deposit has the Payday and Fill envelopes boxes, and Mark as payday asks whether to fill.
- Requires Android 13 or newer.
