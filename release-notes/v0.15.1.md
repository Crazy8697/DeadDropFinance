Updates now download and install themselves, plus a few follow-ups.

- Updates: the Download button on the update bar is now Download and install. It fetches the release file itself,
  checks it against the release's own checksum, then installs it through Android's own installer. The first time,
  if the app isn't yet allowed to install updates, it shows a button to turn that on, then continues on its own.
- Import setup: an Export example button next to Pick a JSON file saves the invented example from docs/IMPORT.md,
  to see the format or use as a starting point.
- Erase everything: no more "There is no backup yet" line; it now points to Backup and restore instead, and only
  says everything is erased when everything really was.
- The contact in the privacy policy and end user agreement is now support@darkrelay.net.
- Requires Android 13 or newer.
