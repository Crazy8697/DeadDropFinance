Dead Drop Finance for Windows 0.6.0 adds the Dead Drop Finance engine.

- The program now carries the same budget engine as the phone app (envelopes, transactions, CSV import, rules and the
  budget math) and keeps its own budget in your profile (`%APPDATA%\DeadDropFinance`), separate from your phone.
- There is no visible change yet: the window still shows the name, the version, the update bar and the Help menu.
  The budget screens come in a later version.
- Updating from 0.5.0: the program offers this version in its update bar. Your settings are kept.
