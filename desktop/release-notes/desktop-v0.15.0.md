Dead Drop Finance for Windows 0.15.0: Reports, new menus and text colors.

- The Reports screen is no longer placeholders: twelve reports, the same as the phone app's, on the budget month in the top bar. Click a report to open it; Back returns to the list.
- New menus with icons and keyboard shortcuts. File: Add transaction (Ctrl+N), Move money (Ctrl+M), Import CSV (Ctrl+I), Import setup, Export CSV (Ctrl+E), Back up (Ctrl+B), Restore, Settings (Ctrl+,), About, Quit. View: every screen from Budget to Sync (Ctrl+1 to Ctrl+8). Help: Check for updates, Licenses, Privacy policy, End user agreement, Support DarkRelay, About. The Edit menu is gone.
- Text is a little brighter and its muted text a little greyer, matching DarkRelay's other Windows programs.
- A Debt envelope can have its interest rate (on its Edit screen). Reports > Debt paydown shows the payoff date and the interest on the way.
- Settings: the Rules card's switch no longer runs into its description, and no other switch does either.
- Updating from 0.14.2: the program offers this version in its update bar. Your budget and settings are kept.
