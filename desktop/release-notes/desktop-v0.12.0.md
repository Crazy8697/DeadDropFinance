Dead Drop Finance for Windows 0.12.0: pick your currency, and restore without typing your key.

- Settings > Budget > Currency: one currency for the whole budget. The common ones come first, then every currency, searchable by code or name. Amounts show and are typed the way that currency usually is, for example 1.234,56 € in euros. It also sets how CSV files are read when a file doesn't show it.
- It's display only: no exchange rates, nothing is fetched, and no amount changes. It syncs with the phone app through your server. A budget that never picked one stays in US dollars.
- Every currency shows two decimal places, since amounts are kept in hundredths.
- Restore now uses the recovery key saved on this computer when it opens the backup, so there's nothing to type.
- Windows Hello unlock is removed.
- An envelope with no target shows nothing in the Target column, instead of a dash.
- Updating from 0.11.0: the program offers this version in its update bar. Your budget and settings are kept.
